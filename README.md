One line (112 characters): the funniest excuse a robot vacuum gives for
missing a spot, written by `main.ts` to `/output/entry.txt` for
[The Robot Vacuum's Best Excuse](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)
on [make.fun](https://make.fun).

## The excuse

> That spot is not dirt. According to my sensors it is a load-bearing crumb, and I will not be the one to test it.

## How it was chosen

Ten candidates were drafted in the build session and scored against the
judge's brief — vacuum's own world, laugh-out-loud, clean turn at the
end, straight-faced vacuum voice. See [CANDIDATES.md](CANDIDATES.md)
for all ten, their scores, and why #10 won.

## Run

```sh
node main.ts   # writes /output/entry.txt (112 characters, one line)
```
